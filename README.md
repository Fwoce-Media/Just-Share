# Just Share

Send files between computers and phones. Windows and Android.

**[Download](../../releases/latest)** · Setup.exe or portable zip

## Features

- Windows ↔ Windows, Windows ↔ Android, Android ↔ Android
- Over Wi-Fi, a hotspot, a network cable or USB tethering
- Finds nearby devices by itself
- Accept or decline every transfer
- Received files go to Downloads\Just Share
- Updates itself
